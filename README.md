# Pension Benefit Simulator

Interactive pension benefit simulator built with Python and Streamlit.

## Features

- Select individual pension participant
- Display participant profile
- Compare MPB 100% monthly vs Mix 20% lump sum + 80% monthly vs mps 100%
- Simulate cumulative pension benefits
- Calculate break-even period
- Generate participant-specific insights

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
